# ☀️SkyCast — Ứng dụng dự báo thời tiết

**URL dự án:** [https://xn1664494-tech.github.io/skycast-weather-app/](https://xn1664494-tech.github.io/skycast-weather-app/)

**GitHub Repository:** [https://github.com/xn1664494-tech/skycast-weather-app](https://github.com/xn1664494-tech/skycast-weather-app)

## ✨ Tính năng chính
- **Tìm kiếm thời tiết:** Nhập tên thành phố để lấy dữ liệu thời tiết theo thời gian thực.
- **Thông tin chi tiết:** Hiển thị nhiệt độ hiện tại, cảm giác như, độ ẩm, tốc độ gió, chỉ số UV và tầm nhìn.
- **Chuyển đổi đơn vị:** Dễ dàng chuyển đổi qua lại giữa độ C (°C) và độ F (°F) chỉ bằng một cú click chuột (sử dụng thuần CSS với `:has()`).
- **Giao diện hiện đại:** Thiết kế tối (Dark mode), hiệu ứng nền động, hoạt ảnh mây và mặt trời được vẽ hoàn toàn bằng CSS.
- **Tương thích:** Giao diện responsive, hiển thị tốt trên cả máy tính và điện thoại.

## 🛠️ Công nghệ sử dụng
- **HTML5:** Cấu trúc trang web.
- **CSS3:** Định dạng giao diện, sử dụng Flexbox, Grid, CSS Variables và các hiệu ứng Animation.
- **JavaScript (ES6+):** Xử lý sự kiện, gọi API và cập nhật DOM.
- **API:** [Visual Crossing Weather API](https://www.visualcrossing.com/) (Cung cấp dữ liệu thời tiết).
